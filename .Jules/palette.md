## 2024-09-21 - Custom Tab Components Accessibility
**Learning:** Custom UI controls created from generic `<div>` tags (like the auth toggle switches) natively lack keyboard focusability, ARIA state bindings, and trigger unexpected behaviors (like form submissions) when styled to resemble buttons. Specifically, applying `role="tab"` requires managing a roving `tabindex` and `aria-selected` to make keyboard navigation function identically to native components without compromising visual styling.
**Action:** When implementing custom toggle/tab interfaces, immediately substitute `<div>` with explicit `<button type="button">`, strip native browser styles, implement manual Arrow Key event listeners to swap `tabindex` (0 vs -1), and ensure `:focus-visible` pseudo-class provides distinct keyboard navigation outlines separate from mouse click behaviors.
