## 2024-08-23 - Custom Tab Navigation Accessibility
**Learning:** Custom UI tab toggles originally implemented as `<div>` elements lacked keyboard focus, structural semantics, and interactive discoverability for screen readers. Default browser focus styling on replacing them with `<button>` elements breaks the original custom visual design.
**Action:** When creating custom tab components, use native `<button type="button">` to retain semantics, explicitly strip browser defaults via CSS, implement ARIA roles (`tablist`, `tab`, `tabpanel`), and provide a roving `tabindex` coupled with explicit `ArrowLeft`/`ArrowRight` event listeners that `e.preventDefault()` to avoid unwanted scrolling and derive state from `document.activeElement`. Always explicitly define a `:focus-visible` outline for keyboard navigation.
