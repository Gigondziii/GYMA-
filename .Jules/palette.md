## 2024-05-24 - Accessible Custom Tab Toggles
**Learning:** In GYMA, custom tab toggles (like Log In vs Sign Up) implemented with `<div>` elements and `onclick` handlers break keyboard accessibility and semantic meaning. Screen readers don't announce them as tabs, and keyboard users cannot easily navigate between them using standard patterns.
**Action:** Replace `<div>` toggles with native `<button type="button">` elements to preserve basic accessibility while stripping default styles to maintain design. Add ARIA roles (`role="tablist"`, `role="tab"`, `role="tabpanel"`), state attributes (`aria-selected`, `aria-controls`), and implement roving `tabindex` with Arrow key navigation to fully meet WAI-ARIA tab pattern standards. Always ensure `:focus-visible` styling uses the primary theme color (`#00ff41`) for clear visibility.
