## 2024-05-18 - Replacing Divs with Native Buttons for Tab Toggles
**Learning:** In `login.html`, custom tab toggles (Login/Sign Up) were originally implemented using `<div>` tags with `onclick` handlers. This caused a loss of native keyboard accessibility. When replacing them with `<button>` elements, custom styling must explicitly clear browser defaults (like `appearance`, `border`, `background`), and the element needs both `role="tab"` and dynamic `aria-selected` attributes. Also, using `:focus-visible` with a distinct outline (using the app's primary `#00ff41` color) is critical since standard buttons lose their default focus ring when styles are heavily customized.
**Action:** When auditing future custom components acting as tabs or toggles, verify they use native interactive elements like `<button type="button">`, have correct ARIA roles (`tablist`, `tab`, `tabpanel`), and explicit `:focus-visible` styling if default focus rings are overridden or obscured by parent elements.
