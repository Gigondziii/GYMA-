## 2024-05-18 - Converting Custom Tabs to Accessible Buttons
**Learning:** In `login.html`, custom tab toggles were initially implemented as `<div>` elements with `onclick` handlers, rendering them completely inaccessible to keyboard users and screen readers. Programmatically calling `focus()` during Playwright tests revealed that modern browsers might not trigger `:focus-visible` styling unless the focus was initiated via real keyboard interaction (like `Tab`).
**Action:** Always replace `<div>` based interactive elements with native `<button>` tags (explicitly `type="button"` to avoid form submission). Add full ARIA role support (`tablist`, `tab`, `tabpanel`), set `aria-selected` dynamically, and explicitly define `:focus-visible` using the design system's accent color (e.g., `#00ff41`) to guarantee keyboard navigation is visible without disrupting mouse-click styles. When testing focus with Playwright, simulate actual `Tab` presses rather than using `.focus()`.
