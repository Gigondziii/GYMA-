## 2023-10-30 - Accessible Custom Tablist Components
**Learning:** Custom UI toggles (like login/signup switches) are often built with `<div>` elements, rendering them completely inaccessible to keyboard and screen reader users. Simply adding click handlers is insufficient.
**Action:** When encountering custom toggle switches, replace `<div>` with native `<button type="button">`. Strip default styles, apply `role="tablist"` to the container, and `role="tab"` to the buttons. Link them to their content using `aria-controls`, `role="tabpanel"`, and `aria-labelledby`. Implement a roving tabindex (`tabindex="0"` for active, `-1` for inactive) and add `keydown` listeners for arrow key navigation using modulo arithmetic to ensure seamless keyboard accessibility. Ensure visual focus rings (`:focus-visible`) are prominent.
