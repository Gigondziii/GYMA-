## 2024-07-22 - Converting Form Toggles to Accessible Tablists
**Learning:** When converting simple inline `<div>` toggles to native `<button>` elements for accessibility, the browser's default button styles (like background, border, and user-agent `outline` on focus) can disrupt the existing visual design if not explicitly overridden. Furthermore, ensuring a semantic tablist pattern (`role="tablist"`, `role="tab"`) requires careful manual synchronization of `aria-selected` and `tabindex` along with custom arrow-key event listeners, as native HTML does not provide automatic roving tabindex out-of-the-box for tablists.
**Action:** Always strip default button styles (`background: none; border: none; font: inherit; color: inherit;`) when substituting `div` elements with `<button>` for semantic interactions to preserve UI fidelity. Additionally, when implementing a custom tab toggle, pair native `<button type="button">` with explicitly styled `:focus-visible` to guarantee keyboard accessibility is clear without creating redundant outlines for mouse users, and ensure keyboard navigation (Arrow keys) aligns with `aria-selected` and `tabindex` properties.
