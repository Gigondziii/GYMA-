## 2024-10-25 - Custom Auth Tab Toggle Accessibility
**Learning:** The existing custom div-based tab toggle for the authentication form lacked keyboard support. Using native `<button type="button">` combined with ARIA roles (`tablist`, `tab`, `tabpanel`) and dynamic states (`aria-selected`, `tabindex`) ensures screen reader support. Arrow key navigation must intercept and prevent the default behavior to stop accidental scrolling, whilst mapping active element to derived tab focus to support "roving tabindex" interaction.
**Action:** When implementing custom tab components instead of using radio buttons or standard navigation links, strip the default browser background/border styles of `<button>` while introducing a custom `:focus-visible` ring utilizing the designated theme accent, and implement explicit `keydown` support for Arrow keys combined with dynamically toggled `tabindex` (-1/0) values.
