## 2024-05-24 - Interactive Form Toggles to Accessible Tabs
**Learning:** When upgrading visual `<div>` toggle switches (like Login/Signup toggles) to semantic `<button role="tab">` elements, adding `:focus-visible` styles and basic ARIA attributes isn't fully sufficient for true accessibility. Custom tab lists require implementing a roving tabindex (`0` for active, `-1` for inactive) and arrow-key navigation (Left/Right) to properly support the W3C ARIA tab pattern for screen readers and keyboard users.
**Action:** When designing custom interactive tabs or replacing generic containers with native buttons, always preserve visual styles by stripping defaults (`background: none; border: none; font-family: inherit;`), use dynamic roving tabindex with Javascript, and implement Left/Right arrow key event listeners with `e.preventDefault()` to avoid unwanted page scrolling.
