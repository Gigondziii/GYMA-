## 2026-08-02 - Accessible Tab Toggles with Native Buttons
**Learning:** When replacing `<div>` based custom toggles with native `<button>` elements for tabbed interfaces, it's critical to strip default browser styles (e.g., `background: none; border: none; outline: none; font-family: inherit;`) to preserve the visual design while gaining native keyboard focus capabilities. Moreover, a robust tab pattern requires implementing a roving tabindex (`tabindex="0"` for active, `tabindex="-1"` for inactive), appropriate ARIA roles (`role="tablist"`, `role="tab"`, `role="tabpanel"`), and arrow-key navigation logic to fully support screen readers and keyboard users.
**Action:** Always implement custom UI tab toggles using native `<button type="button">` elements with explicit style stripping, ARIA roles, and roving tabindex supported by arrow-key navigation events. Ensure the focus styles (e.g., `:focus-visible`) are explicitly defined to match the app's theme color while avoiding unnecessary outlines for mouse interactions.
