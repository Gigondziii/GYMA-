## 2026-07-18 - Convert Custom UI Toggles to Accessible Tablists
**Learning:** This app frequently uses custom UI toggle switches (like the login/signup switch in `login.html`) built with non-semantic `<div>` elements and CSS transitions. These look visually appealing but are entirely inaccessible to screen readers and keyboard users as they lack proper semantic structure, roles, and focus management.
**Action:** Always convert these custom visual toggles into proper accessible tablists. Use semantic `<button type="button">`, apply the `role="tablist"`, `role="tab"`, and `role="tabpanel"` attributes, implement a roving `tabindex` (0 for active, -1 for inactive), and add custom JS event listeners to support arrow-key navigation between tabs while preventing default page scrolling.
