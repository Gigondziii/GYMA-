## 2024-06-25 - Accessible Tab Toggles
**Learning:** Native `<div>` elements used as tab toggles are completely inaccessible to keyboard users and screen readers, lacking semantics, focusability, and interaction context.
**Action:** When creating custom tab toggles, always replace `<div>` with explicit native `<button type="button">` elements. Strip default browser styles (`background: none; border: none; font-family: inherit;`) to maintain original visual alignment. Apply a roving `tabindex` (`0` for active, `-1` for inactive) along with `role="tablist"`, `role="tab"`, and `aria-selected` attributes. Synchronize `aria-selected` and programmatic focus (`.focus()`) on click or arrow key navigation to guarantee the keyboard focus state visually matches the active application state.
