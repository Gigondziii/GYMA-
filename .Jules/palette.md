## 2024-05-15 - Accessible custom tab toggles with roving tabindex
**Learning:** When converting unsemantic `<div>` elements into accessible tab toggles (`role="tablist"` and `role="tab"`), using native `<button>` elements with `type="button"` and stripping default browser styling is crucial. Additionally, implementing a roving tabindex (`tabindex="0"` for the active tab, `-1` for inactive) along with arrow key navigation is necessary to preserve true keyboard accessibility, as screen readers and keyboard users rely on arrow keys to navigate within a tablist component.
**Action:** Always replace `<div>`-based custom interactions with native semantic elements (`<button>`) where applicable, strip default styles to maintain visual design, and implement roving tabindex logic (using modulo arithmetic for clean wrapping) for complex custom widgets like tabs or segmented controls.
