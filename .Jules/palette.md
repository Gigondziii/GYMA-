## 2024-05-23 - Interactive Element Semantics in Legacy HTML Views
**Learning:** The legacy standalone HTML components (e.g., the auth form toggles in `login.html`) frequently rely on `<div>` elements with `onclick` handlers for interactivity. This pattern inherently breaks keyboard navigation (Tab focus) and screen reader support since these elements lack native semantics, default focus states, and keypress event handling (Enter/Space).
**Action:** When updating or adding interactive toggles in the standalone HTML views, always replace generic `<div>` wrappers with native `<button type="button">` elements. Incorporate appropriate ARIA roles (such as `role="tablist"` and `role="tab"`), state attributes (`aria-selected`, `aria-controls`), and explicitly define `:focus-visible` CSS rules to ensure clear keyboard navigation visibility without disrupting default mouse user styles.
