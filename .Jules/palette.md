## 2024-10-08 - Accessible Custom Tab Toggles
**Learning:** When converting custom `<div>` tab toggles (like those used in authentication forms) into native `<button>` elements, mouse clicks might not automatically move DOM focus to the button in all environments. This can disrupt the "roving tabindex" strategy (where `tabindex="0"` is dynamically assigned to the active tab and `-1` to others), as keyboard events relying on `document.activeElement` might not register the newly activated tab.
**Action:** When implementing arrow key navigation via roving tabindex on custom tabs, ensure the JavaScript logic explicitly calls `.focus()` on the newly activated tab button. This guarantees the keyboard focus synchronizes with the visual state, allowing subsequent arrow key navigation to function reliably.
