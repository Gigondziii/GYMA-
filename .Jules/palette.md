## 2024-03-24 - Accessible Tab Toggles
**Learning:** When building custom tab toggles (like the login/signup switch), using standard `<div>` elements breaks keyboard navigation and screen reader support, as they are not natively focusable or semantically identified as tabs. Arrow key navigation must explicitly prevent default scrolling (`e.preventDefault()`) and dynamically handle focus to mirror the visual tab-switching experience for keyboard users.
**Action:** Always replace visual-only `<div>` toggles with native `<button type="button">` elements stripped of default styles. Ensure the parent container has `role="tablist"`, the buttons have `role="tab"`, and their content containers have `role="tabpanel"`. Implement a roving `tabindex` (`0` for active, `-1` for inactive) supported by arrow-key navigation, and synchronize `aria-selected` and `tabindex` dynamically in JavaScript when tabs are switched.
