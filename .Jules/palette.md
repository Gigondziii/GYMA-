## 2024-05-24 - Accessible Custom Tabs via Native Buttons
**Learning:** When building custom tab toggles (like "Log In" / "Sign Up"), using `<div>` elements strips away native keyboard accessibility, and adding `tabindex` alone is insufficient because it lacks native event handling (Enter/Space) and explicit semantic meaning.
**Action:** Always replace `<div>`-based interactive tabs with native `<button type="button" role="tab">` elements grouped within a `role="tablist"`. Strip default browser button styles using CSS (background, border, font-family) and explicitly define a clear `:focus-visible` outline for keyboard navigation. Use a roving tabindex (`tabindex="0"` for active, `-1` for inactive) combined with Left/Right arrow key event listeners to ensure full accessibility without breaking the visual design.
