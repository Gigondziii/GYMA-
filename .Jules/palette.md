## 2024-09-25 - Accessible Custom Tab Lists
**Learning:** When replacing `<div>` elements with native `<button>` elements to improve the accessibility of custom tab components, you must explicitly strip default browser button styling (e.g., `background: none; border: none; font-family: inherit; outline: none;`) to prevent breaking the visual design, while adding clear `:focus-visible` styling for keyboard navigation. Additionally, proper ARIA attributes (`role="tablist"`, `role="tab"`, `aria-selected`, `aria-controls`, `role="tabpanel"`, `aria-labelledby`) and JavaScript-managed roving `tabindex` with arrow-key support are crucial for a fully accessible tab list.
**Action:** Always implement this full suite of HTML, CSS, and JS enhancements when converting generic `<div>` toggles into accessible semantic tabs.
