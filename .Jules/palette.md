## 2024-10-01 - Accessible Auth Tabs
**Learning:** Custom UI tab components frequently lack native accessibility features, particularly keyboard navigation and semantics. Utilizing `<div>` tags with `onclick` handles limits screen reader capabilities and alienates keyboard users. Converting these into native `<button>` elements with `role="tab"` and establishing a roving `tabindex` architecture paired with explicit arrow key navigation enhances usability without disrupting existing layouts.
**Action:** Always replace non-semantic interactive wrappers (`<div>` or `<span>`) with `<button type="button">` or appropriate semantic alternatives, stripping default styling if necessary. Implement complete WAI-ARIA tabbed interface patterns, including `aria-selected`, `role="tablist"`, `role="tab"`, and `role="tabpanel"`. Add clear `:focus-visible` styling using the theme's core accent color. Use roving tabindex for correct arrow key keyboard navigation.
