## 2023-10-27 - Accessible Custom Tab Toggles
**Learning:** When implementing custom tab toggles by converting `<div>` elements to native `<button>` elements, standard default styling must be stripped (`background: none; border: none; font-family: inherit; outline: none;`) to prevent breaking existing designs. A roving tabindex requires dynamic `tabindex` management, explicit `.focus()` calls when tabs are activated via click, and capturing arrow key navigation to handle `e.preventDefault()` to avoid unwanted page scrolling. Modulo arithmetic ensures focus safely wraps across bounds.
**Action:** Always implement a roving tabindex (modifying both `tabindex` and `aria-selected` and handling focus properly via `.focus()`) when replacing custom div toggles with native buttons configured as tabs.
