## 2024-05-18 - Making Custom Toggle Switches Accessible
**Learning:** Custom CSS-based toggle switches (like pill-shaped login/signup toggles built with `div` elements) are completely inaccessible to keyboard and screen reader users by default. Programmatically focusing them doesn't consistently trigger focus indicators.
**Action:** When creating custom tab toggles, always use native `<button type="button">` elements. Strip default browser button styles using CSS (`border: none; background: none; font-family: inherit;`) to retain the custom look, but explicitly add a `:focus-visible` rule to ensure clear keyboard navigation visibility. Additionally, implement ARIA tab patterns: add `role="tablist"` to the container, `role="tab"`, `aria-selected` (toggled via JS), and `aria-controls` to the buttons, and associate them with `role="tabpanel"` and `aria-labelledby` on the corresponding content sections.
