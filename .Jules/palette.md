## 2023-11-20 - Custom Tab Toggles using Native Buttons
**Learning:** When replacing custom `<div>` tab toggles with native `<button>` elements to improve semantic structure and accessibility, it is crucial to strip default browser button styles (`background: none; border: none; font-family: inherit; outline: none;`) within the existing CSS classes to preserve the original visual design. Additionally, programmatic focus management via a roving tabindex requires explicit arrow-key event handlers that invoke `.focus()` and `.click()` while handling `e.preventDefault()` to avoid unwanted page scrolling.
**Action:** Always use `<button type="button">` for non-submitting interactive elements. When styling them, explicitly reset default styles and define a custom `:focus-visible` state that aligns with the application's theme color (e.g., `#00ff41`) to maintain clear keyboard navigation cues without relying on default browser outlines.
