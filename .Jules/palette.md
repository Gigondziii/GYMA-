## 2024-05-18 - Semantic Tab Toggles & Keyboard Navigation
**Learning:** Custom tab toggles built using generic `<div>` elements and `onclick` handlers are invisible to screen readers and completely inaccessible via keyboard navigation. Simply making them focusable is insufficient; true accessible tabbed interfaces require a combination of semantic ARIA roles (`tablist`, `tab`, `tabpanel`), proper `aria-selected` tracking, and a roving `tabindex` (toggling `0` and `-1`) coupled with explicit Arrow key event handling to avoid trap states and match native interaction patterns.
**Action:** When implementing or fixing custom UI tabs, always start with native `<button type="button">` elements to get default keyboard focus handling, explicitly strip the browser styling, and implement the full WAI-ARIA tab pattern with roving tabindex and Arrow key support.
