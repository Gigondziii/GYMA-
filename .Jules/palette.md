## 2024-09-29 - Accessible Tablist Implementation for Custom Toggles
**Learning:** When converting generic `<div>` toggle buttons into accessible native `<button>` elements, you must also structure them as a tablist. This requires applying `role="tablist"` to the container, and `role="tab"`, `aria-selected`, `aria-controls`, and `tabindex` (roving) to the buttons. Finally, the content panels need `role="tabpanel"` and `aria-labelledby`.
**Action:** Next time I encounter a custom UI component like a div-based toggle switch or tab selector, I should immediately apply the WAI-ARIA tab pattern, strip the default button styling with `background: none; border: none; font-family: inherit; outline: none;`, implement `:focus-visible` styling, and add JavaScript logic to support arrow-key navigation.
