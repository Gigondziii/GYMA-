## 2026-07-31 - Accessible Native Button Tabs
**Learning:** Transforming custom `<div>` toggles into fully semantic ARIA tablists requires not just adding `<button>` tags, but also implementing a roving tabindex and handling ArrowRight/ArrowLeft key events to prevent standard page scrolling while allowing smooth keyboard navigation. Additionally, stripping default browser button styles while maintaining explicitly defined `:focus-visible` states ensures accessibility doesn't compromise the original UI design.
**Action:** Always replace `<div>`-based interactive custom tabs with native `<button type="button">` elements using ARIA roles (tablist, tab, tabpanel), roving tabindex management (`0` for active, `-1` for inactive), and arrow-key event handlers that invoke `e.preventDefault()`. When doing so, explicitly clear default button styles (`background: none; border: none; font-family: inherit;`) and apply theme-consistent `:focus-visible` outlines.
