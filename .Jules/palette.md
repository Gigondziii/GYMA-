## 2024-05-19 - Authentication Tab Toggle Accessibility
**Learning:** Custom UI tab toggles using simple `<div>` elements with `onclick` handlers frequently fail accessibility checks by missing semantic HTML, rendering them completely inaccessible to keyboard and screen reader users. The browser's default behavior for focus outlines and Enter/Space interaction cannot be intrinsically triggered without a correct element type or explicit event handling and ARIA specification.
**Action:** Always replace `<div>` wrappers meant for interaction with explicit `<button type="button">` elements. Apply ARIA `role="tablist"` to the container, `role="tab"`, `aria-selected` and `aria-controls` to the interactive toggles, and use `role="tabpanel"` on the corresponding toggled content. Ensure to strip default button styling and explicitly re-add clear, brand-aligned `:focus-visible` states.
